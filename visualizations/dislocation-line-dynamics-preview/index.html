How to read this preview

Two datasets, two different claims

01

Ensemble evidence

The TU Graz files are 300 statistically similar relaxed configurations. Six are selected by total-line-length quantile to keep the browser payload small.

02

Motion evidence

The Frank–Read view uses 20 time-ordered PyDiS snapshots from a 200-step run under fixed σxz = −0.40 GPa. Linear browser interpolation smooths the ten-step gaps.

03

Character color

Color follows |t·b̂|: zero is edge, one is screw, and intermediate values are mixed character.
