Velocity–Verlet in Python and C

PY

Python

def velocity_verlet(r, v, f, dt, box, boundary):
    v += 0.5 * dt * f       # half kick, m = 1
    r += dt * v             # drift
    r, v = apply_boundary(r, v, box, boundary)
    f, potential = forces(r, box, boundary)
    v += 0.5 * dt * f       # second half kick
    return r, v, f, potential

C

void velocity_verlet(Atom a[], int n, double dt,
                     Boundary boundary) {
  for (int i = 0; i < n; ++i) {
    a[i].vx += 0.5 * dt * a[i].fx; /* half kick */
    a[i].vy += 0.5 * dt * a[i].fy;
    a[i].x += dt * a[i].vx;        /* drift */
    a[i].y += dt * a[i].vy;
    apply_boundary(&a[i], boundary); /* wrap, reflect, or free */
  }
  compute_forces(a, n, boundary);
  for (int i = 0; i < n; ++i) {
    a[i].vx += 0.5 * dt * a[i].fx;
    a[i].vy += 0.5 * dt * a[i].fy;
  }
}

Model notes

Reduced units and numerical choices

The direct pair loop evaluates 4,950 unique pairs for 100 atoms. Forces and energy use the same force-shifted potential at a 2.5σ cutoff, so both reach zero continuously. The sliders specify the actual minimum and well depth; the underlying σ and bare LJ energy scale are adjusted internally to keep that marked minimum exact.

The density control specifies ρ* = Nσ2/A. The rectangular cell and triangular spacing scale with σ so that the selected value stays fixed when the potential size changes. In free-surface mode this value describes only the initial placement area because the atoms are not confined afterward. The default ρ* = 0.93 is close to a relaxed low-temperature triangular solid for the displayed interaction; lower densities can be used to explore tensile void formation and phase separation.

Periodic boundaries join opposite edges, rigid walls reflect atoms elastically, and free surfaces apply neither wrapping nor wall reflection. Cohesion can round a molten free cluster through line tension, the two-dimensional counterpart of surface tension. At sufficiently high temperature atoms can evaporate, so an arbitrarily hot cluster is not expected to remain circular.

Temperature removes centre-of-mass translation (198 thermal degrees of freedom). Free-cluster preparation also removes whole-cluster rotation, leaving 197 internal degrees of freedom; total energy still retains all kinetic energy. A weak velocity-rescaling thermostat prepares the system for 1,200 steps, then switches off and resets the clock before the NVE measurement. Changing a model setting starts a fresh plotted and exported trajectory segment.
