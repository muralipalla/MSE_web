Experiment 4 · Alloy solidification

Solute rejection can destabilise a flat front

For kp = CS/CL < 1, the growing solid rejects solute. That boundary layer changes the equilibrium liquidus temperature ahead of the interface. Wherever the actual liquid is colder than its local liquidus, constitutional supercooling exists.

Show the boundary-layer model and criterion

For steady planar growth with no liquid convection and negligible solid diffusion,

CL(z) = C0[1 + (1−kp)exp(−Rz/DL)/kp],   TL(z) = Tm + mLCL(z).

With mL < 0, no constitutional supercooling at the interface requires

GL/R ≥ |mL|C0(1−kp)/(kpDL),   SCS = GLDLkp / [|mL|RC0(1−kp)].

SCS ≥ 1 passes this simple stability test. At R = 0, C0 = 0, or kp = 1, the solutal instability term vanishes.

Scope and primary references

The inequality is a constitutional-supercooling onset heuristic, not the full Mullins–Sekerka morphological-stability analysis. Capillarity, perturbation wavelength, thermal conductivities and fields, interface kinetics, anisotropy, and convection also matter. The changing front is therefore labelled a visual cue, not a deterministic planar–cellular–dendritic prediction.
