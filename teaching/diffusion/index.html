Section 2 · Atomistic interdiffusion

Two-species kinetic Monte Carlo

A fully occupied lattice contains A atoms (blue) and B atoms (orange). Each event selects one nearest-neighbour bond; unlike atoms exchange positions while the total amount of B remains exactly constant.

Model used here

This is an ideal, symmetric interchange model with equal bond rate Γ: periodic boundaries vertically and reflecting, no-flux boundaries horizontally. The stochastic clock reports t* = Γt; a sweep is only an event-count unit. The model captures composition-conserving mixing, not vacancy-mediated diffusion or species-dependent activation barriers.

Section 3 · Continuum description

Fick’s laws of diffusion

When atomic detail is averaged over many sites, concentration becomes a continuous field. Fick’s first law relates flux to a gradient; conservation of matter turns that relation into the time-dependent second law.

Fick’s first law

J = −D ∂C∂x

Flux follows the downhill direction. The minus sign makes J point from high concentration toward low concentration.

Fick’s second law · constant D

∂C∂t = D ∂2C∂x2

Curvature changes concentration. Peaks flatten, sharp interfaces broaden, and total solute is conserved in a closed domain.

Similarity variable

η = x2√(Dt)

For one-dimensional diffusion with constant D, many profiles depend on x and t only through η. That is why every characteristic diffusion depth scales as √(Dt).

Instantaneous planar source · infinite medium

A narrow pulse becomes Gaussian

C(x,t) = M√(4πDt) exp[−x24Dt]

M is the conserved amount per unit area. The peak falls while the variance grows as σ2 = 2Dt.

Diffusion couple · infinite medium

A sharp step becomes an error function

C(x,t) = CL + CR2 + CR − CL2 erf(η)

The midpoint remains (CL + CR)/2 while the interfacial width grows in proportion to √(Dt).

Constant surface concentration · semi-infinite solid

A maintained surface produces an erfc profile

C(x,t) − C0Cs − C0 = erfc(η)

Cs is held at the surface and C0 is the initial bulk concentration. This idealization is widely used for case hardening and constant-source doping.

Use these solutions when: D is constant, transport is one-dimensional, the stated initial and boundary conditions apply, and the domain is large compared with the diffusion depth.

Explicit conservative update

Fluxes cross cell faces

Ji+½ = −D Ci+1 − CiΔx
Cin+1 = Cin − ΔtΔx(Ji+½ − Ji−½)

Boundary-face fluxes are set to zero. What leaves one cell enters its neighbour, so the discrete integral of C stays constant apart from round-off.

NumPy implementation of the same no-flux, conservative explicit scheme.

# Requires: python -m pip install numpy matplotlib
import numpy as np
import matplotlib.pyplot as plt

# Physical domain and constant diffusivity
L = 100e-6                 # m
D = 1e-12                  # m^2 s^-1
nodes = 101
dx = L / nodes
x = -L / 2 + (np.arange(nodes) + 0.5) * dx

# Step initial condition: low concentration | high concentration
C = np.where(x < 0.0, 0.0, 1.0)
C_initial = C.copy()

# Explicit stability: Fo = D*dt/dx^2 must not exceed 1/2 in 1D
Fo = 0.45
dt = Fo * dx**2 / D
target_tau = 0.08          # tau = D*t/L^2
target_time = target_tau * L**2 / D
elapsed = 0.0

while elapsed < target_time:
    step_dt = min(dt, target_time - elapsed)
    # Face fluxes. The two boundary faces remain zero (no flux).
    flux = np.zeros(nodes + 1)
    flux[1:nodes] = -D * np.diff(C) / dx

    # Conservative balance: what leaves one cell enters the next.
    C -= (step_dt / dx) * (flux[1:] - flux[:-1])
    elapsed += step_dt

print(f"Fo = {Fo:.2f}")
print(f"Mass retained = {C.sum() / C_initial.sum():.12f}")

plt.plot(x * 1e6, C_initial, "--", label="initial")
plt.plot(x * 1e6, C, label="finite difference")
plt.xlabel("Position (micrometres)")
plt.ylabel("Normalized concentration")
plt.ylim(-0.03, 1.03)
plt.legend()
plt.tight_layout()
plt.show()

Practical applications

Where controlled diffusion shapes a material

Temperature sets D, time sets the penetration scale √(Dt), and the boundary condition determines the concentration-profile shape.

01

Carburizing steel

At high temperature, carbon diffuses from a carbon-rich atmosphere into austenitic steel. Quenching converts the enriched case into a hard, wear-resistant surface while the lower-carbon core remains tougher.

Useful idealization: constant surface concentration, giving an erfc profile. Case depth grows approximately with √(Dt).

02

Semiconductor doping

Boron, phosphorus, or arsenic can diffuse through silicon during thermal processing. The resulting concentration profile controls junction depth and therefore the electrical behaviour of a device.

Useful idealizations: constant-source predeposition gives an erfc profile; limited-source drive-in approaches a Gaussian profile. Implantation followed by annealing is also common.
